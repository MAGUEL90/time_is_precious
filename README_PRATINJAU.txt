TIME IS PRECIOUS - PRATINJAU PETA TERPISAH

Ini salinan khusus untuk mencoba peta dan bukan pembaruan proyek GitHub.
Ekstrak seluruh isi ZIP ke folder baru yang kosong. Jangan menyalinnya ke
folder proyek Time is Precious yang sudah ada.

1. Tutup editor Godot proyek lama, jika sedang terbuka.
2. Buka Godot 4.5.1, pilih Import, lalu pilih project.godot dalam folder ini.
3. Tunggu proses impor selesai, lalu buka proyek dan tekan F5.
4. Pilih New Game. Bergerak dengan W/A/S/D dan berinteraksi dengan E.
5. Dekati To Be Clean kiri atas (titik 1), tekan E, pilih Assign Player,
   lalu Start Cleaning. Tanda akan hilang dan garis bekas lahan muncul.
   Setelah itu menu menawarkan pembangunan rumah dengan material yang ada.

Save pratinjau memakai direktori khusus bernama
time_is_precious_review_20261103. Save proyek lama tidak digunakan atau
ditimpa. Ini bukan migrasi save lama: jangan memindahkan save antarproyek.

Peta sumber dan tiga marker lainnya dipertahankan sebagai gambar seperti
kiriman terakhir. Hanya titik 1 terhubung ke gameplay rumah; kegunaan titik
2-4 belum ditentukan. Posisi lima sumber bahan hanya untuk pratinjau dan
belum menjadi keputusan layout permanen. Bahan, waktu, needs, dan ekonomi
mengikuti aturan game yang sudah ada; belum dijamin New Game bisa memenuhi
semua kebutuhan warga tanpa bantuan.
