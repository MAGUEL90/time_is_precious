# Synthetic schema-13 house checkpoints

These checkpoints were produced with Godot 4.5.1 and the project's existing
house save regression fixtures on commit `7fab572bf528d4f345f0be312a88a726acdb2929`.
They contain only fixture-generated citizens, inventory and work state, not a
player's save. They cover the authored house while clearing, while building,
and after completion. The built city checkpoint was written after loading the
regression's built-home checkpoint and returning through the actual home door.
The pre-house v11 file is the old-schema fixture
generated by the same regression. New tests decompress a copy in an isolated user profile;
the source bytes are never overwritten.

The SHA-256 digests of the uncompressed checkpoint bytes are:

- clearing: `ba2a8c842ad1ff0986ac73890f623e31f7e3ee538265dfa97304fa8c3c947a7b`
