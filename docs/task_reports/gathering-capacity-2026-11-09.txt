METODE
Godot4.5.1 stable, renderer Compatibility/OpenGL. Harness QA berada di luar repo,
di work/gather_matrix.gd, memakai helper walker yang sudah ada. Pergerakan normal
dan input E melewati gameplay; tidak teleport. Tombol Hourly, Next, dan Start
diaktifkan lewat signal tombol inspector asli. Start ditekan dua kali untuk
memeriksa pencegahan eksekusi ganda. Ini integrasi runtime terotomasi, bukan
pengujian keyboard/mouse fisik atau penilaian kemudahan menemukan fitur.

Tas kosong dimulai dari New Game asli. Dua kondisi kapasitas berikutnya memakai
fixture inventori eksplisit: barang tas dibersihkan lewat API Inventory, kemudian
diisi reed_bundle berbobot1 sampai menyisakan ruang satu unit target atau penuh.
Filler itu bukan barang hasil bermain. max_load tetap100; kebutuhan pemain,
kecepatan jalan50, dan clock1 detik/menit tidak diubah. Tidak ada perubahan stok
alam, aturan hasil, civil, atau format save. Tiap sesi gathering meminta180 menit.
Hasil berkurang antar sesi mengikuti kondisi pemain; angka di bawah adalah
observasi run ini, bukan perubahan balancing atau klaim hasil tetap.
